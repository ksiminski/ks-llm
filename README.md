# Examples of LLM with Python

The repository contains examples of how to use large language models (LLMs) with Python.

## 1-ollama 

Simple example of how to use the [Ollama](https://ollama.com/) API with Python.

## 2-temparature 

Example of how to use the temperature parameter with LLMs in Python. The temperature parameter controls the randomness of the model's output. A lower temperature (e.g., 0.2) will make the output more deterministic, while a higher temperature (e.g., 0.8) will make it more random.

## 3-rag 

Example of how to use Retrieval-Augmented Generation (RAG) with LLMs in Python. RAG combines the power of LLMs with external knowledge sources to generate more accurate and contextually relevant responses. 

## 4-fine-tuning

Example of how to fine-tune a pre-trained LLM with your own dataset in Python. Fine-tuning allows you to adapt the model to specific tasks or domains, improving its performance on those tasks.
